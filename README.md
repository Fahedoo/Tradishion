> **Tradishion** is a web application based on traditional clothing. It aims to allow people around the world to share their traditional outfits and promote cultural diversity. 

In a world where modernization and westernization often overtake cultural legacies, Tradishion is here to maintain our elders' fashion and show the world how rich it is through its diversity of cultures!

---

## ✨ Features

* **Cultural Social Media:** A dedicated platform to share and discover traditional outfits from all around the globe.
* **Multilingual Support:** Dynamic language selection using JSON translation files.
* **User Localization:** Origin flags automatically displayed next to users' profiles.
* **Custom MVC Architecture:** Built from scratch using a Model-View-Controller structure for clean, maintainable, and scalable code.

---

## 🛠️ Tech Stack

This project was built without heavy frameworks to solidify core programming concepts :

* **Back-End:** Vanilla PHP (Object-Oriented Programming & MVC pattern)
* **Front-End:** HTML5, Vanilla CSS, JavaScript
* **Data / Config:** JSON (for translations and data fetching)
